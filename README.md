# 小宇英文：英文段考複習（國一・翰林版七上 Starter～Review 3）

📱 **網址**：https://xiaoyu-1201.github.io/g7-english-review/
（iPad 用 Safari 打開 → 分享 →「加入主畫面」，就像 App 一樣全螢幕使用）

家教上課與學生回家自學用的互動複習，範圍是第一次段考：Starter、Unit 1〈Who's That Handsome Boy?〉、Unit 2〈Where Are My Pencils?〉、Review 1。

## 有什麼

| 功能 | 說明 |
|---|---|
| 16 個單元 | 第 1 堂（Starter＋Unit 1）、第 2 堂（Unit 2＋Review 1），每單元約 10～14 分鐘 |
| 觀念卡 | 先讓學生猜規則，再揭曉重點與易錯提醒（引導式） |
| 9 種題型 | 選擇、複選、填空、整句改寫、重組、抓錯、分類、放位置、聽力 |
| 粗心偵測 | 整句題分開判斷「內容錯」與「格式粗心」（大寫、標點、空格、連字號），逐字標出差異 |
| 引導提示 | 每題的「提示」是一層一層的引導問題，不直接給答案 |
| 有點猜 | 作答前可以標記「有點猜」；紀錄會分出「很確定卻答錯」的題目 |
| 錯題本 | 答錯自動收進來；要隔一段時間再答對兩次才畢業（間隔複習） |
| 模擬段考 | 約 30 題六大題混考，交卷前要走過「30 秒檢查清單」；結果會算「如果沒粗心可以拿幾分」 |
| 閃電挑戰 | 60 秒快問快答（be 動詞、a／an、複數、所有格） |
| 紀錄 | 粗心雷達（點一列直接特訓）、單元精熟度、練習歷程；可匯出／匯入合併、傳文字報告 |
| 今天的任務 | 依段考日期把單元平均分到每一天；每天先做「暖身 5 題」（之前學過的）和錯題本；最後兩天排模擬段考 |
| 先說答案 | 上課模式：選擇題的選項先遮住，學生先口頭回答再看選項（設定裡開關） |
| 錯因自評 | 答錯後點一下「看錯題目／規則不熟／單字不熟／太急了」，報告會統計 |
| 徽章 | 9 個成就（十連對、零粗心、錯題畢業生、第 1／2 堂制霸…） |
| 紙本練習卷 | 每一堂、錯題本都能印成考卷，附解答頁和交卷檢查清單 |
| 其他 | 深色模式、大字、實體鍵盤（1～4 選答案、Enter 檢查、← 上一題）、離線可用、加到主畫面 |
| 上一題 | 每題都能回上一題，看當時的答案與解析（只能看，不重複記錄）；沒寫完的答案會保留 |
| 再練一次 | 結果頁、錯題本點一題，看完上次答案可以直接在面板裡再練一次 |
| 老師後台（2.1） | 一個老師、很多個一對一學生：學生列表（誰正在練習、今天幾題）、每個學生的即時作答、最近常錯的地方；每個學生、每個家庭只看得到自己的紀錄 |
| 三種加入方式 | QR Code（手機相機掃）、連結（LINE 傳）、6 碼代碼（App 裡輸入，7 天有效）；家長連結綁定孩子 |
| 課堂檢視 | 學生用自己的裝置上課時，老師即時看到現在這一題、正確答案、學生的答案與對錯 |
| 學生模式 | 學生沒帶裝置時，老師的平板或手機暫時給學生用：作答算在那個學生的紀錄 |
| 再試一次 | 答錯可以馬上重做（練習中、上一題回顧、模擬段考檢討）；分數照第一次，重做答對不算錯題本畢業 |
| 口說練習 | 跟讀 44 句，瀏覽器語音辨識逐字比對、標出要再練的字；「不看字」模式練段考聽力 |
| 會考導向 | 情境單題、圖表題組（卡片、公告、訊息）、會考聽力（辨識句意、基本問答、言談理解）；每題標題型、考點、選項解析 |
| 模擬段考 | 七大題、配分 100：聽力三部分、字彙、單題、克漏字、閱讀題組、圖表題組、非選擇題 |
| 考點＋選項解析 | 每一題都有考點；選擇題逐一說明每個選項為什麼對、為什麼錯（content.js 的 EXPLAIN 補舊題） |
| 派作業 | 老師在學生頁派作業（單元、模擬段考、口說、錯題本；可以依最近的錯誤自動挑）；學生首頁出現、做完自動打勾；老師收到通知；家長看得到 |
| 跟自己比 | 這週 vs 上週、連續練習天數、模擬段考最高分、閃電挑戰最高；破紀錄會提醒（不跟別人比） |
| 即時同步 | Firebase Realtime Database（規則在 `database.rules.json`）；每台裝置在背景用匿名登入（不用帳號） |
| 成員管理 | 依學生分組的裝置名單；新成員加入會通知；可以移除、允許重新加入、暫停加入、把老師的其他裝置設為可管理 |

## 紀錄留存怎麼用

- 紀錄存在「每台裝置自己的瀏覽器」裡。
- 學生在家練完：**紀錄 → 傳學習報告給老師**（文字，貼到 LINE），或 **匯出備份檔** 傳給老師。
- 老師在平板：**紀錄 → 匯入備份檔**，就會把學生的紀錄合併進來（重複的不會算兩次）。
- 清除瀏覽器資料會刪掉紀錄，記得定期匯出。

## 檔案

| 檔案 | 內容 |
|---|---|
| `content.js` | 第一次段考的題庫、觀念卡、文章、聽力稿（全部自編，不含課本原文）；最下面把 `content2.js`、`content3.js` 合併進來 |
| `content2.js` | 第二、三次段考的範圍（Unit 3～6、Review 2～3）和 `EXAMS`（每次段考的範圍、文章；含「第一冊會考模擬」） |
| `content3.js` | 會考題型 Ⅱ、Ⅲ：情境單題、圖表題組、會考聽力（言談理解的問題最後才念） |
| `app.js` | 練習引擎、批改、錯題本、模擬段考、聽力練習卷、紀錄 |
| `art.js` | 家族樹、介系詞場景、時鐘、月曆、標誌、人物、場景等插圖 |
| `styles.css` | Apple 風格版面（含深色模式） |
| `sw.js` | 離線快取；改版時 `app.js` 的 `VERSION` 和 `sw.js` 的 `CACHE` 都要改 |
| `audio/` | 自然語音音檔（Kokoro 產生）和 `index.json`（文字 → 檔名） |
| `asr.js` | 口說練習的網頁辨識（Moonshine tiny，MIT 授權；transformers.js）：沒有手機辨識的提示音，模型約 28MB，第一次使用時下載 |
| `tests/` | 自動測試（Playwright＋模擬 Firebase）；全部跑：`.\tests\run_tests.ps1`，跑一個：`.\tests\run_tests.ps1 -Tests test_speak.py` |
| `tools/tts/` | 產生音檔：`node tools/tts/collect.mjs` 再 `python tools/tts/synth.py`；模型檔放 `tools/tts/models/`（不上傳） |
| `tools/extract_text.py`、`tools/extract_kaokao.py` | 把教材 PDF 轉成文字，給編題目時查閱（教材本身不在 repo 裡） |
| `tools/check_content.mjs` | 檢查題庫格式（答案位置、空格數、文章、插圖）；`node tools/check_content.mjs` |

純 HTML／CSS／JavaScript，沒有任何套件，不需要建置。本機預覽：`python -m http.server 5181`。

參考用的教材有版權，放在 repo 外面，不放進這個 repo。
