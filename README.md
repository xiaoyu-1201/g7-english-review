# 英文段考複習（國一・翰林版七上 Starter～Review 1）

📱 **網址**：https://xiaoyu-1201.github.io/g7-english-review/
（iPad 用 Safari 打開 → 分享 →「加入主畫面」，就像 App 一樣全螢幕使用）

家教上課與學生回家自學用的互動複習，範圍是第一次段考：Starter、Unit 1〈Who's That Handsome Boy?〉、Unit 2〈Where Are My Pencils?〉、Review 1。

## 有什麼

| 功能 | 說明 |
|---|---|
| 16 個單元 | 第 1 堂（Starter＋Unit 1）、第 2 堂（Unit 2＋Review 1），每單元約 10～14 分鐘 |
| 觀念卡 | 先讓學生猜規則，再揭曉重點與易錯提醒（引導式） |
| 9 種題型 | 選擇、複選、填空、整句改寫、重組、抓錯、分類、放位置、聽力 |
| 粗心偵測 | 整句題分開判斷「內容錯」與「格式粗心」（大寫、標點、空格、連字號），逐字標出差異 |
| 引導提示 | 每題的「提示」是一層一層的引導問題，不直接給答案 |
| 有點猜 | 作答前可以標記「有點猜」；紀錄會分出「很確定卻答錯」的題目 |
| 錯題本 | 答錯自動收進來；要隔一段時間再答對兩次才畢業（間隔複習） |
| 模擬段考 | 約 30 題六大題混考，交卷前要走過「30 秒檢查清單」；結果會算「如果沒粗心可以拿幾分」 |
| 閃電挑戰 | 60 秒快問快答（be 動詞、a／an、複數、所有格） |
| 紀錄 | 粗心雷達（點一列直接特訓）、單元精熟度、練習歷程；可匯出／匯入合併、傳文字報告 |

## 紀錄留存怎麼用

- 紀錄存在「每台裝置自己的瀏覽器」裡。
- 學生在家練完：**紀錄 → 傳學習報告給老師**（文字，貼到 LINE），或 **匯出備份檔** 傳給老師。
- 老師在平板：**紀錄 → 匯入備份檔**，就會把學生的紀錄合併進來（重複的不會算兩次）。
- 清除瀏覽器資料會刪掉紀錄，記得定期匯出。

## 檔案

| 檔案 | 內容 |
|---|---|
| `content.js` | 題庫、觀念卡、文章、聽力稿（全部自編，不含課本原文） |
| `app.js` | 練習引擎、批改、錯題本、考試、紀錄 |
| `art.js` | 家族樹、介系詞場景、字母樓層等插圖（SVG） |
| `styles.css` | Apple 風格版面（含深色模式） |
| `sw.js` | 離線快取；改版時 `app.js` 的 `VERSION` 和 `sw.js` 的 `CACHE` 都要改 |

純 HTML／CSS／JavaScript，沒有任何套件，不需要建置。本機預覽：`python -m http.server 5181`。
